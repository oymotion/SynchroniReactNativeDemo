# 参数用例（PARAM-*）

> 目标对象：`SensorProfile.setParam/getParam`（设备级）与 `SensorController.setParam/getParam`（控制器级）。
> 流开关 key 与 `DataType` 枚举名**不是一回事**：setParam/getParam 的流开关 key 取自 `getParam("NTF")`
> 返回的 `NTF_XXX|ON|...` 列表；角度流 setParam key 是 `NTF_ANGLE`，磁力计无独立开关（随 `NTF_IMU` 聚合）。
> 见 AGENTS.md §9.1。

### PARAM-FUNC-001 getParam("NTF") 返回流开关列表
- **优先级**：P0
- **测试目的**：验证流开关查询。
- **平台**：通用
- **设备相关**：通用
- **流程与逻辑**：Ready 后 `await getParam("NTF")`。
- **预期结果**：返回形如 `NTF_EEG|ON|NTF_IMU|ON|...` 的字符串，各流带 ON/OFF 值，非 `Error`。
- **有效性说明**：流开关权威 key 来源。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### PARAM-FUNC-002 getParam("FILTER") 返回滤波开关
- **优先级**：P1
- **测试目的**：验证滤波开关查询。
- **平台**：通用
- **设备相关**：通用
- **流程与逻辑**：`await getParam("FILTER")`。
- **预期结果**：返回滤波开关列表（如 `FILTER_50HZ|ON|...`），非 `Error`；无滤波能力时返回空/`Error`（记录跳过）。
- **有效性说明**：滤波能力识别。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### PARAM-FUNC-003 setParam 流开关 ON/OFF
- **优先级**：P0
- **测试目的**：验证流开关下发。
- **平台**：通用
- **设备相关**：设备相关（需对应流能力）
- **流程与逻辑**：对支持的流 `await setParam("NTF_XXX", "ON"/"OFF")`，再 `getParam("NTF")` 回读。
- **预期结果**：返回 `"OK"`；回读该流开关值与下发一致。
- **有效性说明**：流开关控制链路。
- **可自动化**：auto

- **测试结果**：通过

### PARAM-FUNC-010 角度流 NTF_ANGLE 独立开关
- **优先级**：P1
- **测试目的**：验证角度流开关 key 与枚举名分离。
- **平台**：通用
- **设备相关**：设备相关（需角度能力）
- **流程与逻辑**：`await setParam("NTF_ANGLE", "OFF")`，观察角度流停、MAG/IMU 不受影响；对比 `setParam("NTF_ANGLE_DATA", ...)`。
- **预期结果**：`NTF_ANGLE` 返回 `"OK"` 且只停角度流；`NTF_ANGLE_DATA`（枚举名）返回 `Error/Not supported`。
- **有效性说明**：SET_KEY 与 STREAM_KEY 分离（AGENTS.md §9.1）。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：跳过

### PARAM-FUNC-011 磁力计无独立开关（随 NTF_IMU 聚合）
- **优先级**：P1
- **测试目的**：验证磁力计聚合开关。
- **平台**：通用
- **设备相关**：设备相关（需 IMU 能力）
- **流程与逻辑**：`setParam("NTF_MAG", "OFF")` 与 `setParam("NTF_IMU", "OFF")`，观察影响。
- **预期结果**：`NTF_MAG` 返回 `Error/Not supported`；`NTF_IMU` 的 OFF 同时停 ACC/GYRO/EULER/QUAT（含磁力计）。
- **有效性说明**：聚合流开关语义。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：跳过
