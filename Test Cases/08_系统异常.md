# 平板系统异常用例（SYS-*）

> 本章覆盖**平板/移动端系统级操作与异常**对 SDK 的影响：蓝牙开关、WiFi 开关、飞行模式、消息/来电打断、
> 前后台切换、锁屏、屏幕旋转、分屏、权限等。
>
> 平台约定（见 README §5.2）：Android 可用系统设置/程序触发并半自动/自动执行；iOS 无法程序化切换蓝牙/WiFi，
> 相关用例标注 `Android(程序化)+iOS(人工)`，iOS 侧由人工在控制中心/设置手动操作。
> 所有用例期望：**不崩溃、状态机与回调一致、恢复后数据/会话可续**。

### SYS-ROB-001 扫描/连接中关闭蓝牙
- **优先级**：P0
- **测试目的**：验证扫描/连接中蓝牙被关的异常处理。
- **平台**：Android(程序化)+iOS(人工)
- **设备相关**：通用
- **流程与逻辑**：`startScan` 或连接过程中关闭蓝牙，观察 `isEnable`、`onEnableChanged`、扫描/连接状态。
- **预期结果**：`isEnable===false` 且收到使能回调；扫描停止/连接失败，无崩溃；重开后可恢复。
- **有效性说明**：蓝牙使能变化是移动端最常见异常。
- **可自动化**：semi-auto
- **人工介入**：人工/程序关闭蓝牙。
- **测试结果**：待测试

### SYS-ROB-002 起流中关闭蓝牙
- **优先级**：P0
- **测试目的**：验证起流中蓝牙断开处理。
- **平台**：Android(程序化)+iOS(人工)
- **设备相关**：通用
- **流程与逻辑**：起流数据正常后关闭蓝牙，观察数据、`onDataTransferStateChange`、`onStateChange`。
- **预期结果**：数据停止；`onDataTransferStateChange` 收到 `false`（链路丢失）；状态掉到非 Ready，无崩溃。
- **有效性说明**：链路丢失的权威推送验证。
- **可自动化**：semi-auto
- **人工介入**：人工/程序关闭蓝牙。
- **测试结果**：待测试

### SYS-ROB-003 蓝牙重开后自动恢复
- **优先级**：P0
- **测试目的**：验证蓝牙重开后的恢复。
- **平台**：Android(程序化)+iOS(人工)
- **设备相关**：通用
- **流程与逻辑**：起流中关蓝牙再开蓝牙，观察 `autoReconnect` 是否使设备回到 Ready 并恢复数据。
- **预期结果**：`autoReconnect===true` 时自动重连并回到 Ready，数据恢复；`false` 时不自动恢复。
- **有效性说明**：蓝牙重开恢复路径。
- **可自动化**：semi-auto
- **人工介入**：人工/程序开关蓝牙。

### SYS-ROB-013 权限授予/撤销（Android 定位/蓝牙）
- **优先级**：P0
- **测试目的**：验证权限变化处理。
- **平台**：Android
- **设备相关**：通用
- **流程与逻辑**：分别撤销 `ACCESS_FINE_LOCATION`、`BLUETOOTH_SCAN`、`BLUETOOTH_CONNECT` 后调 `startScan`/`connect`；再授予后重试。
- **预期结果**：权限缺失时 `startScan` 引导授权，拒绝则返回 `false` 不崩溃；授予后正常扫描/连接。
- **有效性说明**：Android 权限是扫描/连接前置。
- **可自动化**：semi-auto
- **人工介入**：人工切换系统权限。
