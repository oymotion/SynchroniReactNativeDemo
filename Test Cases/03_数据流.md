# 数据流用例（DATA-*）

> 目标对象：`SensorProfile.init/startDataNotification/stopDataNotification` 与 `SensorData` 全部访问器。
> 数据流能力一律运行时按 `getDeviceInfo()` 判定（`ChannelCount > 0` 才测，否则记「设备不支持，跳过」）。
> 多流并存时**按 `dataType` 分桶**，各流 `channelIndex` 独立编号，不可跨流混加（见 AGENTS.md §9.1）。
